Parte dell'Aura Open Source Project

Aura Store è uno dei tanti progetti sviluppati sotto l'ombrello dell'Aura Open Source Project, l'iniziativa comunitaria nata in seno ad Aura Studio Italia, casa madre del software Aura. Domande frequenti

Aura Store è davvero gratuito?expand_more
Sì. Aura Store è gratuito, open source e non richiede obbligatoriamente un account per essere utilizzato. Il codice sorgente è pubblico e consultabile da chiunque.
Che differenza c'è tra Aura Store e Aura Studio Italia?expand_more
Aura Studio Italia è la casa madre del software Aura. Aura Store è uno dei progetti sviluppati sotto l'Aura Open Source Project, l'iniziativa comunitaria che raccoglie i progetti open source legati all'ecosistema Aura.
Posso aggiungere repository personalizzati?expand_more
Sì. Dalle impostazioni dell'app puoi aggiungere qualsiasi repository compatibile con il formato di Aura Store per ampliare il catalogo delle app disponibili.
Come posso contribuire al progetto?expand_more
Puoi contribuire con codice tramite pull request, segnalare bug, o partecipare alle discussioni della community. Ogni contributo è benvenuto.
